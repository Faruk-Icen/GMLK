# Maintenance policy

GMLK is a volunteer-maintained project. Issues and pull requests are reviewed on a best-effort basis, usually during the maintainer's available development time. A response within 24 hours is not guaranteed.

Bug reports should include a small reproduction, the GMLK version or commit, and relevant Studio Output messages. The maintainer will label actionable reports, ask for missing details when needed, and prioritize security issues and regressions affecting the current release. Feature requests are evaluated for fit with GMLK's focused module startup and utility APIs.

For vulnerabilities, use the private reporting instructions in [SECURITY.md](SECURITY.md). Please do not put secrets or player data in public issues.
