**Title:** Show HN: GMLK – a Luau module loader kit for Roblox games

**Submission URL:** LIVE_DEMO_URL

**First comment:**

I built GMLK to give Roblox projects a predictable way to start client and server modules: require everything, run `Init` in order, then run `Start`. It also includes focused helpers for remote argument validation, per-player rate limiting, signals, time, numbers, and cleanup.

The source, Rojo coin-counter example, tests, and setup steps are at https://github.com/Faruk-Icen/GMLK. The Studio example prints balance and rate-limit feedback in the Output panel. The project is MIT licensed.

I'd especially appreciate feedback from Roblox developers on the loader's API and whether the example makes the setup clear. GMLK is early stage, and I want to keep the core small and useful.
